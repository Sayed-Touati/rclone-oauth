Privacy Policy

Last updated: November 4, 2026

Purpose

This is a personal, non-commercial integration using Rclone to synchronize files between Google Drive and a personal Linux computer.

Data Access

The integration requests access to Google Drive files to perform authorized file operations, including listing, downloading, uploading, modifying, and deleting files.

Data Storage

Files are transferred between the user's Google Drive account and local computer. Authentication credentials are stored locally by Rclone.

Data Sharing

This personal integration does not intentionally sell or share Google Drive data with third parties. Data is processed through Google Drive and the locally installed Rclone application.

Data Control

The user controls which files are synchronized and can revoke access through their Google Account security settings.
